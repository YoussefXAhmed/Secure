# 🔐 Password Manager Web App

A full-stack password manager web application that allows users to securely store, manage, and organize their credentials.

---

## 🚀 Features

* 🔑 Secure password storage
* 🧾 Add / Edit / Delete credentials
* 🗑️ Trash system for deleted items
* 🔍 Search functionality
* ⚡ Fast and responsive UI
* 🔐 Basic authentication system (if implemented)
* 🎨 Clean modern design with Tailwind CSS

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Axios
* React Hot Toast (for notifications)

### Backend

* Node.js
* Express.js
* MongoDB (if used)

---

password-manager/

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YoussefXAhmed/password-manager.git
cd password-manager
```

---

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

---

### 3. Run frontend

```bash
npm start
```

---

### 4. (Optional) Run backend

```bash
cd ../backend
npm install
npm start
```

---

## 🌐 Deployment

### Frontend (Vercel)

* Deploy the `frontend` folder using Vercel

### Backend (Optional)

* Deploy using Render / Railway / AWS

---

## ⚠️ Important Notes

* Do NOT upload `node_modules`
* Make sure `.gitignore` includes:

```
node_modules
.env
build
```
